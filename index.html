Lab Philosophy

The 3 Tiers

Everything we build belongs to one of three tiers — from everyday micro-utilities to heavy-duty systems engineering.

🍋

Lemon Tier

Everyday micro-utilities. Simple, lightweight, instant startup, zero configuration — built to streamline a developer's daily workflow.

  • Fast native binaries (Rust)
  • Zero configuration
  • Instant startup
  • CLI + GUI options
  • Headless mode (--dry-run, --json)
🟩

Lime Tier

Deeper technical tools and visual studios. Feature-rich environments used less frequently for heavier workflows, built by and for developers.

  • Visual studios & workspaces
  • Local AI coding agent
  • MCP, shell & file execution
  • 14 gradient themes
  • Web + Electron desktop
🧪

Acid Tier

High-performance, complex, heavy-duty projects engineered for advanced developers and low-level systems work.

  • Game engine development
  • Low-level systems work
  • Advanced performance tuning
  • Developer-facing internals
  • 🚧 In active development
Standalone Project

PipeCraft

Visual CI/CD pipeline editor for GitHub Actions. Build workflows by connecting nodes on a canvas, with two-way YAML sync, DevSecOps validation checks, GitHub runner cost estimation (FinOps), an AI assistant (Cmd/Ctrl + K), and local runs via act.
